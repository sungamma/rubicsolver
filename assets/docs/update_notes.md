# 更新说明

## 1.1.3

- 主页新增随机魔方入口，可生成 18～25 步合法打乱并同时显示完整公式和对应状态，无需扫描即可进入编辑与求解。

## 1.1.2

- 支持在主页重新配置 U、R、F、D、L、B 六个面的标准颜色，选择已使用颜色时自动交换。
- 自定义配色会一致应用于扫描方向提示、颜色识别、拍照后改色、校验编辑和三维解法播放。
- 解法播放在魔方上方显示当前转动公式，双转按相同转动速度延长为两倍动画时长，并收紧窄屏布局。

## 1.1.1

- 启动后每七天自动检查一次新版本，发现更新时展示更新说明，由用户确认下载并调用系统安装器。
- 手动检查和自动检查统一改用 heat ex 项目的 HTTPS 更新服务器，并使用 Rubik Solver 独立的版本、APK 与更新说明文件。
- 增加 Android Release 一键部署脚本，自动发布正式签名 APK、版本文件和更新说明。

## 1.1.0

- 实时提示改用固定标准色参考与逐帧校正，不再因历史中心色累积而越扫越不准；六面完成后按每色九格进行全局最小代价分配。
- 固定白色为 U、绿色为 F，并用颜色名称提示每一面的拍摄方向。
- 相机实时预览使用透明识别边框，识别色圆点移到格子中心；支持单格锁定、整面锁定和全部解锁。
- 每面拍照后可立即点击非中心格改色，手动修改会自动锁定。
- 用户确认识别提示后，只要颜色数量与魔方物理状态合法，就不再因低置信度或画质提醒阻断求解。
- 播放页修正最后一步、后退和公式跳转的旋转动作，并剔除不可见贴纸，避免颜色穿透魔方实体。
- Android 启动图标更新为深蓝背景、完整三面九格的打乱六色魔方。

## 1.0.0

- 支持按 U、R、F、D、L、B 顺序扫描 3×3 魔方六个面。
- 支持颜色识别后的合法性校验、贴纸编辑和错误提示。
- 使用 Kociemba 两阶段算法生成快速解法，并提供逐步播放与动作说明。
- 求解期间支持取消等待，播放页适配 320dp 窄屏并区分当前动作和已完成动作。
- 增加作者、隐私、第三方许可和更新说明页面。
- 相机照片仅在本机处理；更新检查和 APK 下载均为可选功能。
