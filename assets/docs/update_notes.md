# 更新说明

## 本轮扫描与三维播放改进

- 相机实时预览改为透明识别边框和小色点，保留真实魔方颜色；支持单格锁定、整面锁定和全部解锁。
- 用户确认识别提示后，只要颜色数量与魔方物理状态合法，就不再因低置信度或画质提醒阻断求解。
- 播放页改用六面三维贴纸投影，支持拖动查看、复位标准视角、顺逆时针/180°方向箭头和 2.4 秒慢动作。
- Android 启动图标更新为深蓝背景六色魔方主题矢量图标。

## 1.0.0

- 支持按 U、R、F、D、L、B 顺序扫描 3×3 魔方六个面。
- 支持颜色识别后的合法性校验、贴纸编辑和错误提示。
- 使用 Kociemba 两阶段算法生成快速解法，并提供逐步播放与动作说明。
- 求解期间支持取消等待，播放页适配 320dp 窄屏并区分当前动作和已完成动作。
- 增加作者、隐私、第三方许可和更新说明页面。
- 相机照片仅在本机处理；更新检查和 APK 下载均为可选功能。
