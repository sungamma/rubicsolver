# 扫描识别、即时纠色、图标与播放修正设计

**日期：** 2026-08-09  
**状态：** 已批准，直接实现

## 目标

在只支持标准三阶魔方配色的前提下，提高扫描过程中和六面完成后的颜色识别稳定性；允许每面拍照后立即改色并自动锁定；明确“白色为 U、绿色为 F”的扫描方位；把实时识别圆点移到方格中心；用规整的打乱 3×3 立体魔方替换现有不完整图标。同时修复本轮代码审查发现的三维播放动作与遮挡错误。

标准配色固定为：白 U、红 R、绿 F、黄 D、橙 L、蓝 B；不再宣称兼容任意中心配色。

## 已确认的问题与根因

### 实时提示随扫描进度下降

`ScanPreviewClassifier` 当前先建立标准色参考，再逐面用历史照片的原始中心色覆盖。不同照片可能具有不同曝光、白平衡和反光；完成面越多，实时帧所使用的历史参考越多，参考系越不一致，因此提示准确率会随扫描进度下降。

### 识别与锁色过早绑定

实时预览把一次临时分类得到的 `CubeFace` 直接保存为锁色结果。旧设计还允许任意中心配色，因此在六中心完成标定前，这个面标签可能并不稳定。新设计固定标准配色，并只把用户明确选择或明确锁定的标准颜色作为硬约束。

### 单面预览不能直接纠色

拍照后的预览只能展示识别色和锁状态，点击格子不能选择目标颜色。用户必须等到六面全部完成后才能在编辑器纠正，反馈回路过长。

### 扫描方位缺少物理颜色锚点

页面只提示 U/R/F/D/L/B 与“某面朝上”，但没有先声明白色中心定义 U、绿色中心定义 F，用户容易按不同物理方向采集，导致贴纸二维方向不符合状态编码。

### 图标与三维播放

现有图标的可见面没有完整 3×3 网格，造型不像规整魔方。播放页则把完成后高亮的 `currentMove` 当成本次状态过渡动作：最后一步没有旋转，后退会旋转错误动作，跨步跳转会伪装成单层旋转。三维画布还缺少背面剔除，隐藏贴纸可能穿透实体面。

## 颜色识别设计

### 统一颜色特征

新增稳定的标准色参考模型，六个参考颜色来自 `CubePalette`。每次实时帧或照片只使用该帧自己的中心贴纸做光照偏移校正，不再读取历史照片的原始中心色作为实时参考。

校正过程在 Lab 空间进行：已知当前面的标准中心色，把当前帧中心色到标准中心色的亮度与色偏差作为该帧的受限偏移，并应用到同一帧九格。偏移必须限幅，避免过曝、阴影或错误中心把整帧推向异常区域。

颜色距离使用 CIEDE2000；在低饱和区域加强对白色的判断，在黄色与橙色、红色与橙色等邻近色之间保留色相差作为辅助代价。中心格始终强制为当前扫描面。

### 实时提示

实时提示只处理当前九格：帧内校正后对固定标准色板分类，返回首选颜色、次选颜色、距离差和画质状态。扫描进度不会改变参考色板，所以同一画面在第 1 面与第 6 面应得到相同结果。

实时网格保持透明背景和标准色边框；每格的识别色圆点移到正中心。用户仍可点击格子或整面锁定；锁定的是标准颜色身份。

### 拍照与即时纠色

拍照后的单面预览显示九格结果。点击非中心格弹出六色选择器；选择颜色后立即更新该格并自动锁定。中心格不可改，固定为当前面颜色。重拍清空当前面的临时修改；接受此面后，样本与显式锁色一同保存。

### 六面全局分类

六个中心固定。每面先执行独立的帧内 Lab 校正，再为所有未锁定的非中心贴纸计算到六个标准颜色的 CIEDE2000 代价。

最终分配使用全局容量约束：扣除已锁定贴纸后，每种颜色补足到 9 枚，以最小总代价分配其余贴纸。实现可采用展开为颜色槽位的 48×48 最小代价匹配。若用户锁定结果已经使某色超过 9 枚，则不覆盖用户选择，退回逐格首选分类并交给现有颜色数量校验报告硬错误。

置信度由首选与次选的代价差计算；手动锁定格不产生不确定提示。分类结果继续进入现有颜色数量、边角块、翻转、扭转和奇偶性校验。

## 扫描方向与提示词

进入扫描前显示固定基准：

- 白色中心面定义为 U（上面）。
- 绿色中心面定义为 F（前面）。
- 保持中心配色为标准关系：白对黄、绿对蓝、红对橙。

扫描顺序保持 U → R → F → D → L → B，但页面同时显示颜色名称、面字母和应朝上的颜色：

1. 白 U：蓝色边朝上。
2. 红 R：白色边朝上。
3. 绿 F：白色边朝上。
4. 黄 D：绿色边朝上。
5. 橙 L：白色边朝上。
6. 蓝 B：白色边朝上。

README 与页面文案使用同一份方向定义，避免字母提示和颜色提示漂移。

## Android 图标

采用用户选择的 B 方案：深蓝背景、规整的打乱 3×3 等距魔方。三个可见面各有完整九格；顶部整体以白色为主、前面中心为绿色、右面中心为红色，其余格使用六色打乱布局。

前景图形保持在 Android adaptive icon 安全区内，同时保留 v21 layer-list 和 v26 adaptive icon。必须在圆形和圆角矩形蒙版下检查缩放、居中和裁切。

## 三维播放修正

把“状态过渡动作”和“完成后当前动作高亮”拆开：

- 前进一步：过渡动作是刚被应用的动作。
- 后退一步：过渡动作是被撤销动作的逆动作。
- 最后一步仍保留过渡动作，完成后才清空当前高亮。
- 跨多个步骤的公式跳转不伪造单层动画；直接更新状态并禁用本次层旋转。

三维渲染对变换后的面法线做背面剔除，并把可见实体面与贴纸放入一致的深度顺序；旋转中的贴纸同样参与可见性判断，避免隐藏贴纸穿透。

## 测试与验收

- 单元测试证明实时分类不随 `capturedSamplesByFace` 数量改变。
- 光照偏移、红/橙、白/黄、低饱和白色和低质量样本测试。
- 全局分配确保无锁色时每色 9 格；锁色会减少对应容量；锁色超量保留并产生现有硬错误。
- Widget 测试覆盖圆点居中、拍照后点格选择六色、手动改色自动锁定、中心不可改和重拍清理。
- Widget 测试覆盖白 U 绿 F 基准与六面颜色方向提示。
- 播放测试覆盖最后一步、后退逆动作、跨步跳转无单层动画；投影测试覆盖背面剔除。
- Android XML 可解析，并对图标安全区做资源级检查。
- 完整执行格式化、`flutter analyze`、`flutter test`、Release-only APK 构建和签名证书比对。

## 范围边界

- 不引入机器学习模型或远程识别服务。
- 不支持非标准中心配色。
- 不修改求解算法或魔方状态编码。
- 不交付 Debug APK，只交付使用同级 `heat_ex_designer` JKS 签名的 Release APK。
