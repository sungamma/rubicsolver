# 花式魔方图鉴与逐步演示设计

## 目标

在现有扫描、随机打乱和求解之外，增加“花式魔方”学习入口。用户从完整复原的 3×3 魔方出发，选择经典花式后可以先查看成品六面展开图，再通过现有三维魔方逐步执行标准公式，最终得到所选花式。

首版聚焦离线、确定性的经典公式，不加入联网下载、用户自定义公式、收藏、搜索或排行榜。

## 用户流程

1. 主页在“随机魔方”和“手动录入”之间增加“花式魔方”入口。
2. 点击后进入花式图鉴，顶部说明统一持握方向：逻辑 `U` 面朝上、逻辑 `F` 面朝前，过程中不要整体转动魔方。
3. 图鉴卡片显示花式名称、难度、动作数、简短特征和由真实目标状态渲染的六面展开预览。
4. 点击卡片直接进入逐步演示。演示始终以 `CubeState.solved()` 为初态，以该花式公式为动作序列。
5. 用户可使用上一步、下一步、自动播放、速度切换和公式跳转；完成时显示“花式完成”。
6. 返回图鉴后可选择另一种花式。所有状态和公式都在本机生成。

主页当前配置的 `CubeColorScheme` 会同时传给图鉴预览和三维演示，因此花式只描述逻辑面，不强制用户使用标准实体颜色。

## 首批花式目录

目录采用仅含 `U/R/F/D/L/B` 的 Singmaster 外层转动，避免现有动作解析器不支持 `M/E/S/x/y/z` 的问题。

| 标识 | 名称 | 难度 | 公式 |
| --- | --- | --- | --- |
| `six-spots` | 六面点 | 入门 | `U D' R L' F B'` |
| `checkerboard` | 棋盘格 | 入门 | `U2 D2 R2 L2 F2 B2` |
| `four-spots` | 四面点 | 进阶 | `F2 B2 U D' R2 L2 U D'` |
| `cube-in-cube` | 立方体中立方体 | 进阶 | `F L F U' R U F2 L2 U' L' B D' B' L2 U` |
| `snake` | 蛇形 | 挑战 | `R2 F2 U2 R B2 U2 F2 L2 D' R2 F2 U2 R' D B2` |
| `superflip` | 超级翻转 | 挑战 | `U R2 F B R B2 R U2 L B2 R U' D' R2 F R' L B2 U2 F2` |

每个条目还包含一句描述，用于说明最终图案的主要视觉特征。公式是唯一状态来源：目标状态必须通过 `CubeSolver.applyMoves(CubeState.solved(), moves)` 计算，不能手工保存 54 枚贴纸。

## 领域模型

新增不可变 `CubePattern`：

- `id`：稳定、唯一的英文标识，用作 Widget key 和后续数据迁移标识。
- `name`、`description`、`difficulty`：中文展示信息。
- `moves`：构造时从公式解析并复制为不可变列表。
- `notation`：以空格连接的标准公式。
- `targetState`：从复原态执行全部动作得到的状态。
- `moveCount`：动作列表长度。

`CubePatternCatalog.patterns` 暴露固定、不可变且保持展示顺序的目录。构造阶段拒绝空标识、空名称、空公式和重复标识；目录测试同时验证每个目标状态物理合法、彼此不同且不是复原态。

## 界面结构

新增 `PatternGalleryPage`，不引入独立详情页，以减少一次无必要的导航：

- 页面标题为“花式魔方”。
- 顶部说明卡明确“从复原态开始”和固定 `U/F` 朝向。
- 宽度小于 600dp 时使用单列卡片；更宽时使用双列网格。
- 每张卡片上半部使用只读 `CubeNet` 展示最终状态，关闭中心锁图标；下半部显示名称、难度、动作数、描述及“开始演示”。
- 预览沿用传入的 `CubeColorScheme`，卡片点击区域具备明确语义和稳定 key。

主页窄屏继续纵向排列四个主要入口；宽屏改为可均分的两行或自适应换行，避免四个按钮在 600dp 附近挤压文字。

## 逐步播放复用

保留 `SolutionPage` 的现有状态机、三维渲染和控制器，只增加可选的展示文案参数：

- `title`，默认“解法演示”；花式传入“<名称>演示”。
- `completionText`，默认“复原完成”；花式传入“花式完成”。
- `formulaTitle`，默认“完整解法”；花式传入“完整拼法”。

默认值保证现有求解流程和测试行为不变。花式图鉴传入 `CubeState.solved()`、目录动作、当前配色和上述花式文案。逐步状态仍由 `MovePlayer` 每次从初态重算，跳转和后退不会累积误差。

## 边界与错误处理

- 目录公式在应用启动前由常量数据构造；任何非法动作应在测试中暴露，不在界面静默忽略。
- 不支持中层转动、整 cube 转动或括号重复记号；所有展示公式必须能由现有 `CubeSolver.parseAlgorithm` 解析。
- 用户必须从物理复原态开始。首版仅提供明确提示，不使用相机确认用户实体魔方是否复原。
- 图鉴预览只读，不允许点击贴纸修改花式。
- 花式完成后不自动进入求解页；用户可以后退或重新播放。

## 测试与验收

- 领域测试验证目录数量、顺序、唯一标识、公式解析、不可变性、目标状态合法性、非复原且互不重复。
- 为每个目录条目保存目标 facelet 快照，防止日后无意改动经典公式。
- 图鉴 Widget 测试验证六个条目、目标预览、难度和动作数，点击后以复原态及相同动作进入演示。
- 配色测试验证主页配置的颜色方案传递到图鉴 `CubeNet` 和演示 `Cube3DView`。
- 播放测试验证花式标题、“完整拼法”和完成文案，同时确保默认求解文案保持不变。
- 320dp 图鉴和主页无布局溢出，600dp 以上使用双列布局。
- 完整执行格式检查、静态分析与全部 Flutter 测试。

## 发布范围
