# 扫描锁色、确认放行与三维引导设计

## 目标

在现有实时识别和三维播放基础上解决四类实际使用问题：扫描提示层遮挡真实贴纸、识别颜色会随帧抖动且无法锁定、用户已确认颜色后仍被低置信度阻止求解、三维播放缺少视角控制和明确的转动方向；同时将 Android 启动图标替换为魔方主题图标。

## 方案比较与选择

### 扫描锁色

1. 仅冻结整帧：实现简单，但无法单独纠正某一格，也不能把确认结果带到最终分类。
2. 每格手动选择颜色：控制最强，但拍摄时要重复打开选择器，操作过重。
3. 每格点击锁定当前识别，并提供一键锁定九格：既能防抖，又保持拍摄流程快速；锁定映射随该面保存并覆盖最终自动分类。

采用方案 3。中心格始终固定为当前面；非中心格点击后锁定当前标准色，再次点击解除。一键按钮可锁定当前九格或全部解除。

### 三维播放

1. 保留固定 U/F/R 视角，只增加按钮和箭头：风险低，但不能查看背面，仍不是真正可查看的三维魔方。
2. 引入外部 3D 引擎：功能丰富，但增加依赖、包体和长期维护风险。
3. 将现有 `CustomPainter` 扩展为六面三维投影，支持拖动观察、标准视角复位和当前层旋转动画。

采用方案 3。使用轻量三维向量和透视投影，不添加第三方依赖。动画以旧 `CubeState` 的 54 枚贴纸为几何来源，将属于当前层的贴纸绕对应轴旋转，动画结束后切换到新状态。

## 扫描交互

- 实时提示层不再用 72% 不透明色覆盖整格。每格只保留标准色细边框和右上角小色点，真实魔方贴纸始终可见。
- 小色点显示识别色首字；低画质只用小型警告标记，不再扩大红色覆盖范围。
- 点击任意非中心格锁定当前识别色，出现锁图标；再次点击解除。中心格显示固定锁图标。
- 取景框下方提供“锁定当前九格 / 全部解锁”按钮和一句操作提示。
- 拍照后高分辨率样本仍是最终颜色数据；锁定映射只覆盖对应格的面标签，不篡改原始 RGB。
- 重拍当前面会清除该面的临时锁；接受该面后锁定映射进入 `ScanSession`，重新扫描该面时一并删除。

## 确认与求解放行

- 物理合法性仍是硬门槛：颜色数量、块组合、翻转、扭转和奇偶性不合法时绝不求解。
- 低置信度、过暗、过曝和光线不均改为软警告。校验页提供“我已核对，使用当前颜色”按钮。
- 用户确认后隐藏低置信度高亮和重复警告；只要 `CubeValidator` 判定状态合法，“开始求解”立即可用。
- 用户逐格编辑仍会清除对应格的未确认状态。全局确认只作用于当前识别结果，不改变魔方状态。

## 三维视图与动作引导

- 画布渲染六个面，并按视角和深度只绘制朝向相机的贴纸。
- 单指拖动改变水平/垂直视角；垂直角限制在不会翻转操作方向的范围内。
- 画布左上角提供“复位视角”按钮，恢复标准 U/F/R 观察角度。
- 画布旁显示随动画轻微旋转的方向箭头：顺时针、逆时针和 180° 使用不同图标/文案，并保留标准记号。
- 播放速度增加“慢动作 · 2.4 秒”，三维层旋转动画时长随播放速度变化，且短于下一步计时，避免动画重叠。
- 画布下方显示“拖动查看其他面 · 点复位视角回到标准方向”的固定引导。

## 图标

Android 使用自适应图标：深蓝背景、黑色魔方骨架、白/红/绿/黄/橙/蓝六色贴纸。Android 21–25 使用同构矢量图标，Android 26 及以上使用 adaptive icon。图标资源不包含文字，保证小尺寸辨识度。

## 数据结构

- `ScanSession.acceptCurrent` 新增 `lockedFaces` 参数，并保存 `Map<CubeFace, Map<int, CubeFace>>`。
- `ColorClassifier.classify` 新增同名锁定映射输入；锁定格不加入低置信度集合，也不产生自动纠错 hint。
- `CubeEditorPage` 新增本地 `_recognitionWarningsAcknowledged` 状态，求解条件变为“物理合法且警告为空或已确认”。
- `Cube3DView` 保存 `yaw`、`pitch` 和上一状态；`Cube3DPainter` 接收视角、动作和动画进度。
- `MovePlayer` 支持 500、900、1400、2400 ms 四档速度。

## 测试与验收

- 扫描 Widget 测试断言提示格背景近乎透明、存在锁定按钮、点击单格后图标变为锁定，并确认锁定映射传入会话。
- 分类单元测试断言锁定颜色覆盖自动分类，且锁定格不会进入 uncertain/hints。
- 编辑器 Widget 测试断言警告初始阻断、确认后合法状态可求解、非法状态确认后仍不可求解。
- 三维测试断言拖动改变 painter 视角、复位按钮恢复默认角度、方向箭头随动作变化、慢动作档可选。
- 图标资源通过 XML 解析和 Android debug/release 构建验证。
- 最终运行格式化、`flutter analyze`、`flutter test`、Debug/Release APK 构建和签名验证。

## 自审结论

设计没有未决项。锁色只覆盖标签不伪造照片数据；确认只解除识别质量门槛而不绕过物理校验；三维交互不改变求解状态机；图标修改限定在 Android 原生资源。范围覆盖用户最新列出的全部问题。
