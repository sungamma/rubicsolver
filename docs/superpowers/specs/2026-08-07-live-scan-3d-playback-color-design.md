# 实时识别、三维还原与标准配色设计

## 目标

在不改变现有六面扫描、纠错和 Kociemba 求解流程的前提下完成三项改进：相机取景时直接显示九格识别色；还原页用三维魔方播放步骤；所有编辑与播放界面使用稳定、饱和且符合常见 URFDLB 配色的标准色，而不是受拍摄光线影响的原始中心 RGB。

## 方案比较

1. 引入第三方 3D 魔方组件。开发量较小，但会增加依赖、许可证和版本兼容风险，且难以与现有 `CubeState`/`MovePlayer` 精确同步。
2. 自建完整 27 块透视几何与逐层旋转引擎。视觉最真实，但明显超出这轮改进范围，手势、遮挡排序和六面贴纸姿态都会扩大风险。
3. 使用 Flutter 原生 `CustomPainter` 绘制 U/F/R 三个可见面的等距三维魔方，状态切换时插值动画；同时在现有播放器中保留步骤、公式和控制器。此方案没有新依赖，状态来源仍只有 `CubeState`，容易测试和维护。

采用方案 3。三维视图表达空间关系并随还原步骤连续更新，不在本轮增加自由旋转相机或物理级分层转动。

## 架构

### 相机实时识别

`ScanCameraController` 新增图像流能力，并把插件的 `CameraImage` 转为与插件无关的 `ScanCameraFrame`。`CameraFrameSampler` 从经过朝向修正的中央方形区域按 3×3 网格稀疏取样，支持 Android YUV420 和 iOS BGRA8888。`ScanPage` 对图像流节流，避免重复处理；新样本到达后立即更新取景框上的九格覆盖层。

`ScanPreviewClassifier` 使用已采集中心色、当前面的中心样本和标准色板建立 Lab 参考色。每格选择 Delta E 最小的颜色，当前面中心格固定为当前面，以避免中心色被光线误判。覆盖层显示标准色与中文色名；低质量格保留警告边框。拍摄按钮仍调用高分辨率照片采样，作为接受该面的最终数据来源。

图像流启动失败不会阻断拍照，只隐藏实时结果并给出非致命提示。生命周期切换、打开编辑器和释放相机时由控制器停止图像流。

### 三维还原播放

新增 `Cube3DView` 和 `Cube3DPainter`。画布用三个四边形网格绘制 U/F/R 可见面，黑色基体、贴纸间隙、阴影和高光共同表达立体结构。输入仍是不可变 `CubeState`；状态变化时保留上一状态并在固定时长内插值贴纸颜色，同时用当前 `SolutionMove` 标记正在执行的面。

`SolutionPage` 用三维视图替换二维 `CubeNet`，保留进度、中文动作说明、播放/暂停、上一步/下一步、速度和可跳转公式。`MovePlayer` 的状态机无需改变，自动播放与手动跳转都会驱动同一个三维视图。

### 标准配色

显示色固定为常见竞速魔方 URFDLB 色板：白 `#FFFFFF`、红 `#B71234`、绿 `#009B48`、黄 `#FFD500`、橙 `#FF5800`、蓝 `#0046AD`。扫描中心 RGB 继续用于识别计算，但不再覆盖编辑器和播放器的显示颜色。这样既保留动态识别能力，也避免环境光导致灰白、粉红或暗蓝。

## 数据流

相机图像流 → `ScanCameraFrame` → `CameraFrameSampler` → `StickerSample[9]` → `ScanPreviewClassifier` → 标准 `CubeFace[9]` → 取景九格覆盖层。

高分辨率拍照 → 现有 `FaceSampler` → 六面 `ScanSession` → 现有 `ColorClassifier` → `CubeState` → 校验/求解 → `MovePlayer.currentState` → `Cube3DView`。

## 测试与验收

- 单元测试验证 BGRA/YUV 取样、90° 朝向映射和预览颜色分类。
- Widget 测试验证相机图像流到来后九格标准色直接显示，且拍照流程仍可用。
- 色板测试锁定六个标准十六进制颜色，并验证扫描中心色不再改变 UI 显示色。
- 播放页测试验证存在 `Cube3DView`、不存在二维 `CubeNet`，步进后画布状态更新，窄屏控制无溢出。
- 最终运行 `dart format --output=none --set-exit-if-changed .`、`flutter analyze`、`flutter test` 和 Android debug APK 构建。

## 自审结论

设计没有未决占位符。实时流只负责即时反馈，照片仍负责最终采集，二者职责不冲突；标准色只作用于显示，动态中心色仍用于分类；三维视图只替换播放呈现，不改变求解或状态机。范围集中在本次三项需求内。
